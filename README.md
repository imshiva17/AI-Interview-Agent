# AI Interview Agent

AI Interview Agent is a real SaaS-style full-stack platform that helps users prepare for interviews through AI-powered resume analysis, question generation, mock interview practice, and intelligent feedback.

## 🚀 Features
- Upload Resume (PDF)
- AI-Generated Interview Questions
- Technical & HR Interview Practice
- Intelligent Performance Feedback
- Credit-Based Access System
- Razorpay Credit Purchase Integration
- Firebase Google Authentication
- Smooth UI with Framer Motion
- Full Stack Deployment on Render

## 💻 Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Firebase Authentication
- Razorpay
- Framer Motion
- Render

## 📚 What This Project Demonstrates
- SaaS Architecture
- Backend Structuring
- Authentication System
- Payment Gateway Integration
- Credit Management System
- Production Deployment

## 🌍 Deployment
Deployed on Render for full-stack production use.
